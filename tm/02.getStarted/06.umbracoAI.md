---
title: Translate with Umbraco.AI
---

If your site already uses [Umbraco.AI](https://docs.umbraco.com/umbraco-ai), the Umbraco.AI connector lets Translation Manager translate content through the AI connections and profiles you have already set up. You don't need to add a second set of API keys to Translation Manager.

This page takes you from a site with Translation Manager installed to a translated page.

## Before you start

You need:

- Umbraco 17 with [Translation Manager installed](../01.install.mdx).
- A [translation set](03.Configure.md) with at least one target language.
- An account with an AI provider supported by Umbraco.AI (for example OpenAI), and an API key for it.

## 1. Install Umbraco.AI and a provider

Umbraco.AI is installed from NuGet. Install the core package and the package for your AI provider. For OpenAI:

```cli
dotnet add package Umbraco.AI
dotnet add package Umbraco.AI.OpenAI
```

Other providers have their own packages. See the [Umbraco.AI documentation](https://docs.umbraco.com/umbraco-ai) for the list.

Build and start your site, then in the backoffice:

1. Add a **connection** for your provider and enter your API key.
2. Create a **chat profile** that uses that connection and the model you want to translate with.

The connection holds the API key and the profile holds the model and its settings. Translation Manager uses the profile. It never sees the key.

## 2. Install the connector

```cli
dotnet add package Jumoo.TranslationManager.UmbracoAi
```

The connector depends on the [AI connector](../04.Extending/05.connectors/14.AIcon/14.AIcon.md) (`Jumoo.TranslationManager.AI`), so NuGet installs that too. The Umbraco.AI connector plugs into it as one of its translators.

Rebuild and restart your site.

## 3. Choose the AI profile

1. Go to the **Settings** section.
2. Expand **Translation Manager** in the settings tree and open **Connectors**.
3. Open the **AI Connector**.
4. In the **AI Library** dropdown, select **Umbraco AI Connector**.
5. In **Umbraco AI Profile**, pick the chat profile you created in step 1.
6. Save the settings.

If you leave the profile empty, the connector uses Umbraco.AI's default chat profile.

The rest of the AI connector settings, such as the prompts, [batch mode](../04.Extending/05.connectors/14.AIcon/18.batch.md) and translation memory, work the same way as they do for any other AI library. The model comes from the Umbraco.AI profile, not from the AI connector's model setting.

## 4. Make it the default connector on your translation set

You can skip this step and pick the connector each time you send content. Setting it on the set means editors don't have to.

1. Go to **Settings** > **Translation Manager** > **Sets** and open your translation set.
2. In the **Connector** option, select the **AI Connector**.
3. Save the set.

See [creating a translation set](../03.userGuide/04.create.md#Connector) for the other set options.

## 5. Translate a page

1. In the Content section, right-click a page in your source site.
2. Select **Send to translation**.
3. Choose the target languages, and whether to include child pages.
4. Click **Start Translation**.

Translation Manager creates a job and sends the content to your AI provider through Umbraco.AI. When the translations come back, the job is ready to [check](../03.userGuide/02.check.md) and [approve](../03.userGuide/03.approve.md).

## Umbraco.AI connector or AI connector?

Both connectors send content from your site straight to the AI provider, using your own API key. Neither sends content through Jumoo. They differ in where the AI is configured.

Use the **Umbraco.AI connector** when:

- Umbraco.AI is already installed, or you plan to use it for other things on the site.
- You want one place to manage AI providers, keys and models for the whole site.
- You want editors to be able to ask Umbraco.AI's chat assistant to translate a page. The connector adds a `translate_page` tool for this. See the [connector's tools documentation](https://github.com/Jumoo/Jumoo.TranslationManager.UmbracoAI/blob/v17/main/docs/tools.md).

Use the **[AI connector](../04.Extending/05.connectors/14.AIcon/14.AIcon.md)** on its own when:

- You don't use Umbraco.AI and don't want to add it just for translation.
- You want to set the provider, key and model in Translation Manager's own settings.
- You need a provider the AI connector supports directly that you haven't set up in Umbraco.AI, such as a local Ollama model.

You can switch between them at any time by changing the **AI Library** on the AI connector settings page.
