---
title: Translate in place
---
:::note
Translate in place is in Translation Manager 18.1.0 and later. On v17 it is in the first release after 17.10.0.
:::

Translate in place translates a page where it stands, with no translation set. It is useful for a page that doesn't belong to a set, such as a copy of an existing page that still holds the original language.

What happens to the page depends on its document type:

| Document type | What translate in place does |
|---|---|
| Varies by culture | Writes the target language alongside the source language. The source language doesn't change. |
| Invariant | Overwrites the page's own values with the translation and saves a new version. |

:::caution
On an invariant page the translation replaces the original text. An invariant page holds one set of values, so the source language is gone once you approve the job. You can get it back with a rollback.
:::

## Turn it on

Translate in place is off by default. Turn it on in `appsettings.json`:

```json
"Translation": {
    "inPlaceTranslation": true
}
```

The toggle on the Translation Manager settings page shows the current value, but you can't change it there.

You also need at least one connector set up, because translate in place sends the page through a connector like any other job.

## Translate a page

Editors need the send to translation permission. There are two ways to start:

- Open the actions menu on a page and choose *Translate in place*.
- Open the page's [Translations tab](20.transTab.md) and click *Translate in place* in the Languages box.

Then:

1. Under *Translate from*, pick the language the page is written in today.
2. Under *Translate to*, tick one or more languages.
3. Pick the connector to use.
4. Start the translation.

You get one job per target language. Each job appears in the Translation section with a *View* link at the end of the process.

## Approve the job

Check and [approve](03.approve.md) the job as you would any other. The translation only reaches the page when you approve it, so you can edit the values during review.

After approval, use the page's version history if you need to go back to the earlier values.

## What it doesn't do

Translate in place only works on the page you start it from. It has no set, so it has no set settings to change, and it doesn't create or link a target page.

On v17 it only covers documents. v18 also covers library elements.
